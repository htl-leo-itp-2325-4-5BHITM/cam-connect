# Neue Geräte verwalten
Klicken Sie oben links auf die Schaltfläche **„Geräte verwalten“**.

## Geräteübersicht
- Nun werden Ihnen alle Geräte der **links ausgewählten Gerätetypen** angezeigt.
- Falls Sie Geräte aus einer **CSV-Datei** importieren möchten, klicken Sie auf **„Importieren/Exportieren“** und laden Sie Ihre Datei in das Importieren-Fenster.
- Andernfalls klicken Sie oben links auf die Schaltfläche **„Neu erstellen“**.
- Wählen Sie Ihren **Gerätetyp** aus. Falls Sie ein Set erstellen wollen, klicken Sie auf **Geräteset**.

## Gerät erstellen
- Geben Sie den **Namen des Geräts** an.
- Optional kann ein **Bild** ausgewählt werden.
- Konfigurieren Sie alle **Details** zu Ihrem Gerät.
- Abschließend können Sie noch einen **Tag** auswählen (z. B. *Slow Motion*).
- Falls alles korrekt eingegeben wurde, klicken Sie auf **„Gerät erstellen“**, um das Gerät zu erstellen.
